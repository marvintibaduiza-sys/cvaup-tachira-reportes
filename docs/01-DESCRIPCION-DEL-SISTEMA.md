## 3. Problema que resuelve

Antes del sistema, el seguimiento de las actividades técnicas en CVAUP Táchira presentaba dificultades operativas:

| Problemática previa | Impacto |
|---------------------|---------|
| Reportes en papel o archivos Excel dispersos | Imposibilidad de consolidación rápida |
| Sin geo-referenciación estructurada | No se podía cruzar actividad con ubicación |
| Búsqueda manual de información histórica | Días de trabajo administrativo por consulta |
| Sin trazabilidad de responsabilidades | Auditorías difíciles |
| Sin respaldo institucional automatizado | Riesgo de pérdida total de información |
| Reportes oficiales armados manualmente | Demoras en respuesta a entes contralores |
| Sin métricas operativas en tiempo real | Decisiones basadas en intuición, no en datos |

---

## 4. Solución propuesta

Una plataforma web única, de acceso administrado, que **digitaliza completamente el flujo operativo** desde el registro de actividad hasta la generación de reportes oficiales firmables.

### 4.1 Capacidades centrales

```
┌─────────────────────────────────────────────────────────────────┐
│                  SISTEMA DE REPORTES TÉCNICOS                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Registro de actividad     →   Consolidación instantánea        │
│  Geo-referenciación        →   Análisis territorial             │
│  Constancia fotográfica    →   Evidencia documental             │
│  Reportes PDF oficiales    →   Entrega con cintillo institucional │
│  Exportación masiva        →   Respuesta a entes contralores    │
│  Respaldo cifrado          →   Continuidad operativa            │
│  Dashboard ejecutivo       →   Métricas en tiempo real          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 Módulos del sistema

| # | Módulo | Función |
|---|--------|---------|
| 1 | **Dashboard** | Panel ejecutivo con indicadores en tiempo real, semáforo de cumplimiento de técnicos, alertas y gráficos de tendencia. Exportable como informe ejecutivo PDF con cintillo institucional. |
| 2 | **Reportes** | Registro de actividades técnicas: ubicación, fecha, técnico responsable, personas atendidas, rubro agrícola, fotografías y resumen narrativo. Cada reporte genera un PDF oficial firmable. |
| 3 | **Técnicos** | Catálogo del personal de campo con cédula, especialidad, foto institucional y estado activo/inactivo. |
| 4 | **Ubicaciones** | Árbol jerárquico Estado → Municipio → Parroquia → Comuna → Consejo Comunal con los 2.207 consejos comunales reales del Estado Táchira. Soporta importación masiva desde Excel. |
| 5 | **Exportación** | Generación masiva de reportes en PDF (entrega oficial) y Excel (análisis y trazabilidad). Filtros por rango de fechas, técnico, municipio o estado del reporte. |
| 6 | **Respaldo** | Generación manual y automática de respaldos cifrados (AES-256) de la base de datos completa más fotografías. Política de retención FIFO de 10 respaldos. |
| 7 | **Configuración** | Gestión del perfil del administrador y cambio de contraseña con políticas robustas. |

## 5. Beneficios cuantificables

### 5.1 Reducción de tiempos operativos

| Tarea | Tiempo previo (manual) | Tiempo con el sistema | Reducción |
|-------|------------------------|----------------------|-----------|
| Registrar un reporte técnico | 30-45 min (formularios papel) | 3-5 min | **~90 %** |
| Consolidar 100 reportes mensuales | 2-3 días (transcripción Excel) | < 1 minuto | **~99 %** |
| Responder solicitud de entes contralores | 1 semana (búsqueda en archivo físico) | 2 minutos (filtro + exportación) | **~99 %** |
| Localizar reportes por municipio | Imposible sin tabular manualmente | < 5 segundos | **inmediato** |
| Generar informe ejecutivo del mes | 1 día completo | < 30 segundos | **~99 %** |
| Recuperación ante pérdida de datos | No había respaldo, era pérdida total | Restauración desde respaldo cifrado | **garantía total** |

### 5.2 Cumplimiento normativo

- ✅ **Ley de Simplificación de Trámites**: tiempos de respuesta reducidos de días a minutos.
- ✅ **Plan de la Patria 2.5.5**: digitalización efectiva de un proceso institucional clave.
- ✅ **Constitución Art. 141**: eficacia, eficiencia y rendición de cuentas mediante reportes auditables.
- ✅ **Decreto 825**: uso de tecnologías digitales en la gestión pública.

### 5.3 Seguridad institucional

| Componente | Implementación |
|------------|----------------|
| Cifrado de respaldos | AES-256 (estándar militar) |
| Acceso al sistema | Cuenta administradora única + política de contraseñas fuertes |
| Headers de seguridad HTTP | Content-Security-Policy, HSTS, X-Frame-Options, Cache-Control no-store |
| Protección anti-CSRF | Activa en todas las operaciones |
| Anti SQL Injection | Parametrización completa de consultas |
| Anti XSS y formula injection | Sanitización en exports Excel |
| Rate limiting | Anti-DoS en endpoints pesados |
| Validación de archivos | MIME real, tamaño máximo, recompresión defensiva |
| Auditoría de seguridad | Realizada y documentada (24 hallazgos identificados, todos corregidos) |

### 6.1 Tecnologías utilizadas

Todas las tecnologías seleccionadas son **estándares industriales abiertos**, sin dependencias de licencias propietarias:

- **Backend**: Laravel 11 (PHP) — el framework PHP de mayor adopción en gobierno latinoamericano
- **Frontend**: Vue 3 + Inertia.js — interfaces reactivas modernas sin complejidad innecesaria
- **Base de datos**: MySQL 8 — soportada por todos los hostings institucionales
- **Servidor web**: Apache/Nginx — software libre con soporte mundial
- **Generación de PDF**: DomPDF — librería abierta sin costo de licenciamiento

### 6.2 Independencia tecnológica

El sistema funciona **completamente on-premise** en infraestructura institucional. **No depende de servicios externos**:
- ❌ No envía datos a la nube
- ❌ No requiere conexión a APIs de Google, Microsoft o Amazon
- ❌ No usa servicios SaaS de pago
- ✅ Toda la información reside en el servidor de la institución

Esto garantiza **soberanía de datos** alineada con la política nacional.
